# Personal Portfolio

A personal responsive portfolio website built with vanilla HTML, CSS, and JavaScript.

## Files Structure
* `index.html`: Contains the semantic structure and sections of the portfolio.
* `style.css`: Handles styling, dark/light theme variables, and responsive layout.
* `script.js`: Implements dynamic interactions (theme toggle, typing effect, mouse star effect).
* `assets/`: Holds the profile photo and CV file.

## How to Run
Open `index.html` in any web browser.
